2 · Zoom untuk stylus (Z)

Z = tool Zoom: klik = zoom in, Alt+klik = out, seret atas/bawah = zoom halus, seret kotak = zoom ke area itu. Tahan Z = sementara (lepas → kembali ke pen). Persentase muncul di dekat kursor. Coba: klik papan dulu, lalu tekan/tahan Z.
