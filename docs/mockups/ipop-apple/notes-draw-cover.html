Hover the cover → Change cover. Pick “Upload → Choose image…” to see the upload, then drag the photo. “Try a 14 MB file” shows the size error.

How it behaves

  • Stored on the NAS like other note images; resized to about 2000 px wide so pages stay fast.
  • Reposition: drag, then Save. Everyone sees the same crop.
  • Only people with Can edit see these controls.
  • Shows in the chat card, sidebar hover preview and exports.
  • A Notion photo cover now imports as a real cover.

Applied

Hover a suggestion to see where it is; click Apply. Undo restores the page exactly. Click a line in the table of contents to jump to that heading.

Checks

  • Untitled page → title from the first heading
  • Runs of empty lines
  • Heading levels that skip (H2 → H4)
  • A list split by an empty line
  • A bare link → bookmark card
  • Long page (3+ headings) without a contents block → add one

Table of contents

Insert with /toc. It follows the headings live; clicking a line scrolls there.

Type '/' for commands…

Tools

  • Select, pen, highlighter, eraser
