List + detail

Mail-style split

  • Click rows: the blue highlight glides; the detail rises in.
  • Webhook arrives → toast slides in, row moves to its new section, pill pops, the progress bar fills, the new activity row flashes, nav badge bumps.
  • Open / All slides; search highlights matches as you type.
  • Click the "synced" line to resync; Copy number ticks.
/tickets/new

One calm page

  • Pick a queue: tile ring + icon pop; categories re-enter staggered. Oracle / developer queues collapse the category step into one fixed line.
  • Priority and category use the sliding indicator. Critical expands the reason field.
  • Counters turn amber near the limit; "Saving… → Draft saved" after you pause.
  • Drop files on the box (or click it): accepted files rise in, rejected ones shake; × collapses them.
  • Submit now fails on purpose — the .mp4 is rejected: scroll, red ring, shake. Remove it and submit again → spinner → success sheet with drawn check.
  • "Discard draft" → Undo snackbar.
Conditional

Hardware installation

  • Only for queues with supportsHardwareInstallation; picking the chip expands this card.
  • Month arrows slide the grid; past days and weekends shake instead of selecting.
  • Selected day and slot pop; the summary line updates.
  • Slots are iDesk's 08:00–11:00 and 14:00–15:00 on the hour.

After submit

Sent, sending, failed

  • Sending…: iDesk timed out; iPop retries with the same reference, so no duplicates. When it lands the row moves to Open and the reference turns into the iDesk number.
  • Couldn't send: "Try again" fails once (callout shakes), succeeds the second time.
  • Discard → row collapses + Undo.
