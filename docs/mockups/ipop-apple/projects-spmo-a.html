ℹ
How progress is counted. Done tasks add their full weight, every other status adds 0. Progress = weight of done tasks ÷ weight of all tasks. Try typing a weight or changing a status above.
NEW

Weight column

An optional column in Table (top-level tasks). Empty = 1, so projects that never use it keep exactly today's numbers.
NEW

Contribution %

Read-only: this task's share of the whole project. It's what "if this is done, it's worth X%" means in the KPI sheet.
CHANGED

Progress label

Under the header bar it says "weighted progress" once any task has a weight, otherwise "tasks done" as today.
