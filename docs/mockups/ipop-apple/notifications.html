In sync with iPop

How the sync works (one list on the server; the web page and the Notifier only display it):

  1. A new chat message arrives → the server updates the chat group row for that conversation (one row per chat, not one per message), then sends a toast/popup.
  2. Read in the Notifier → also read on the web, the bell badge and the taskbar badge all go down together (and the other way round).
  3. Open the chat in /chat → that chat's group row is marked read automatically.
  4. Reply, Snooze and Delete do the same thing everywhere.
  5. Kept for 90 days; read chat rows are removed after 30 days, since the messages are still in /chat.
