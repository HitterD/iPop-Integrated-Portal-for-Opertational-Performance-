1Where the menus live

  • New page ▾ → Import…: imports into My pages (root).
  • Row ⋯ → Import here… and page ⋯ → Import here…: the imported pages become sub-pages of that page.
  • Export… in the page ⋯ menu and the sidebar row ⋯ menu.
  • Print / PDF is a shortcut for Export → PDF on this page only.
  • Export all pages in the sidebar footer, next to Trash.
  • Import only shows to users with notes.write. Export shows on any page you can open (Can view or above).

2Import dialog

  • You can drop a file onto the dialog, or drop it straight onto the sidebar to open the dialog already filled in.
  • The file is read in the browser, so the summary (format, number of pages and attachments) appears before you press Import.
  • Destination: defaults to My pages. When opened from "Import here…" it defaults to Inside a page with that page selected.
  • Under a shared page, the imported pages inherit its sharing, following the existing rule. Otherwise they are private.
  • Importing the same file again always makes a new copy. A warning shows if it was imported before.
  • A zip over 100 MB or over 300 pages is refused with a clear message, before anything is uploaded.

3Progress

  • One row per page, in tree order. Attachments upload to the NAS notes area, the same storage editor uploads use.
  • If one page fails, the others carry on. Failures are listed in the result.
  • Stop keeps the pages already imported and skips the rest.
  • A multi-page zip gets one top-level page named after the export (here "SJA ICT Wiki"), so it lands as one tidy branch in the tree.

5Export one page

  • Markdown / HTML: a single page with no attachments downloads as one file. Anything with sub-pages or attachments becomes a zip, with one folder per page like Notion.
  • Highlights, toggles, callouts and to-dos in Markdown use the same notation as Notion's export, so the zip imports back into Notion or iPop.
  • PDF opens a print preview (browser print). With sub-pages ticked, they follow on new sheets in tree order. Images are embedded.
  • Export runs in the browser and only includes pages you can open (Can view or above).

6Export all

  • A full backup: one zip with your whole tree, each top-level page as its own folder.
  • Shared with me is off by default and goes into a separate Shared with me/ folder when ticked.
  • No PDF option here: a whole-workspace print isn't useful.
  • The zip is built in the browser and streamed to disk, so large exports don't need server space.
