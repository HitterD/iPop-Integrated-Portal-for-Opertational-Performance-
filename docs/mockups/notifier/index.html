Behaviour
  • 1 notification = 1 popup; it stays until closed or acted on. Max 3 visible (setting), the rest queue behind “+N more” and are always in the tray inbox.
  • Full-screen app / Windows Focus / Busy → popups held and marked “missed” in the inbox; urgent still shows. Popups never steal keyboard focus from your work until you click them.
  • Mail: full message, Reply / Reply all inline (bold, italic, list, attach), Mark read, Open in iPop. Other modules: Reply / Join / Accept / Acknowledge / Mark done / Call back, then Open on the web — already signed in.
  • When the app runs on a PC, iPop's browser toasts on that PC stop, so nothing comes twice.
