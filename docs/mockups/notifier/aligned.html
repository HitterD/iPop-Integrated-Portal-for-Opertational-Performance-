iPop Notifier: aligned popups · Maximize · Light/Dark

1 · Every popup, same size (440 × 560)

Header is neutral (same as the window), module colour only in the icon chip and the main button. Every window has – □ ✕ (double-click the header also maximizes). Padding 20 px, gaps 16 px. Footer is always: one full-width main button + one row of equal buttons. Only the message area scrolls.

2 · Maximized: comfortable reading

Maximize shows the whole message with large text (title 30 px, body 20 px), a centred column of ~70 characters, attachments and images in full. No "Show full message"; everything is already here. □ becomes "Restore".

3 · Settings: Appearance + fixed logo

General → Appearance: System (default) / Light / Dark, applies to every open Notifier window immediately. The iPop logo now sits on a white plate with padding (before: stretched onto a green square, corners clipped). Selection and toggles use iPop green.

4 · Sign in with browser: one tab, closes itself

The click re-uses an iPop tab that is already open (no new tab every time). After the Notifier is connected the page shows this for 2 seconds and closes itself; if the browser does not allow closing, it returns to where you were.

5 · iDesk tickets: problem title + people, never a code

Title is always the problem. The person line tells who: on the user's side the PIC/technician, on the technician's side the reporter. What happened is one plain sentence. The ticket number is only a small grey chip; the GUID never appears. Windows toasts (chat) use the same text.
