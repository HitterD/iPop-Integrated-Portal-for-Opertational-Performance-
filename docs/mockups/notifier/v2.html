1 · One window per notification, grouped on the taskbar (like EPop, modernised)

Every notification opens its own window, slightly cascaded, newest in front. All of them sit under one iPop icon on the taskbar with the count. Hover the iPop icon to see a preview of every window (click one to bring it front, ✕ to close it). Windows never steal the keyboard while you type elsewhere. Close one and it's gone; it stays in the tray Inbox. Images show inside the window. Each window is a light native window (shared engine, no browser per window), so 10+ windows stay light.

Behaviour
  • One real window per notification (mail, iDesk, meeting, memo, projects, notes, calls). Chat stays a Windows toast with the iPop logo.
  • New windows cascade 28 px down-left from the last; the newest is in front with a coloured outline. Max ~8 on screen, older ones auto-minimise to the taskbar group — still listed in the hover preview and the Inbox.
  • Windows keep the keyboard where you are typing; they take focus only when clicked.
  • “Hold during meetings” keeps new windows minimised in the group (the badge still counts) until you're back.
  • Images load from iPop/iDesk only, downscaled for the window; “Show full message” opens a larger reader. One shared rendering engine for all windows keeps memory low.
