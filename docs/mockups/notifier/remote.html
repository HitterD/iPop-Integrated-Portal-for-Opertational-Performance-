1 · Remote session — what ICT sees (left) and what the user sees (right)

ICT works in a full window: the user's screen at up to 60 fps (fps and ping always shown), toolbar with Control / View only, monitor, Smoothest/Best quality, Ctrl+Alt+Del, clipboard sync (text, images, files), send file, chat, media. The user sees a large “ICT is helping you” window with your media — it is not sent back to ICT (the little label on the left says it's there). Minimise it on either side and it minimises on the user's screen. A green frame stays round the user's screen while the session runs.

2 · Asking the user first (30 seconds)

Every session starts with this prompt unless Admin marked the PC unattended (kiosk, server). It stays on top, doesn't take the keyboard, and closes as “declined” after 30 s. A second ICT asking to join gets the same prompt, marked view only.

3 · My media — each ICT's own pictures and videos

Upload once, pick during any session. Stored on the NAS through iPop (JPG, PNG, GIF, WEBP, MP4, WEBM · up to 200 MB each, 2 GB per person). Videos play muted unless you switch sound on. Nothing picked = the built-in iPop “ICT is helping you” animation.

Behaviour
  • Office network only (LAN + the four sites). Video H.264 from the graphics card, 60 fps target; native up to 1440p, steps down to 1080p/900p when the line is busy — fps and ping always visible.
  • Clipboard both ways: text, images and files (big files show progress). Chat lives only for the session — never stored.
  • The media window is excluded from screen capture, so ICT never sees it; “Minimise on user” minimises it on the user's PC; the user can minimise it too. End session is always one click for the user.
  • UAC prompts, the lock screen and Ctrl+Alt+Del need the optional iPop Remote Helper service (installed by ICT once). Without it those show black and ICT sees a hint.
  • A second ICT can watch (view only) after the user allows it; control can be handed over.
