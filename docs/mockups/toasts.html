Toast redesign — all toasts share one neutral material

One set of tokens (--toast-bg / --toast-border / --toast-shadow) for notif banners, action toasts and the call pill. Module colour lives only in the icon tile and the badge. No rail, no coloured border, no coloured glow, no tint. Timer is a 2px grey line visible only on hover. Cards marked hover are shown in their hovered state (close button, “Open →” in place of the time, timer).
